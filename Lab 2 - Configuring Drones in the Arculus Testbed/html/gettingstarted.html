Purpose of the Lab

Purpose of this lab is to introduce you to configuring and managing node clusters on the Arculus Zero-Trust edge-security testbed. In this module, you will prepare, enroll, and approve compute nodes (EC2 instances) so that they can securely participate in Arculus operations. You will perform hands-on activities such as generating join scripts from the Arculus Portal, running enrollment commands on EC2 instances, approving device join requests, and verifying that each device successfully joins the Arculus-managed cluster.

Goals/Outcomes
  • Generate secure join scripts for EC2 nodes using the Arculus Portal.
  • Run join scripts on EC2 instances to request membership in the Arculus cluster.
  • Approve device join requests through the Device Management Dashboard.
  • Verify successful node registration under “More Devices in the Cluster.”
  • Understand how Arculus establishes trusted identities for downstream mission workflows.
  • Prepare a complete node cluster that can be configured as drones in the next module.
