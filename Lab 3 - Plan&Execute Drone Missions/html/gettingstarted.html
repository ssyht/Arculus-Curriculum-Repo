Purpose of the Lab

Purpose of this lab is to introduce you to Zero-Trust mission planning and execution on the Arculus edge-security testbed. In this module, you will learn how to design, validate, and execute a secure drone mission using the Arculus Ground Control Portal. You will configure mission parameters, assign operational roles to your trusted drones, select mission destinations using the interactive map, and generate encrypted mission manifests for repeatable deployments.

Goals/Outcomes
  • Plan a drone mission using the Mission Planning Dashboard and configure mission parameters.
  • Assign mission roles to trusted drones (controller, surveillance, supply, relay).
  • Select a mission destination using the interactive map interface.
  • Generate, download, and validate encrypted mission manifests (.mconf).
  • Understand how Arculus detects manifest tampering and enforces mission integrity.
  • Execute missions using the Mission Execution Dashboard.
  • Monitor live drone telemetry, mission logs, and movement during execution.
  • Observe dynamic network policy creation/removal using Task-Based Access Control (TBAC).
  • Simulate adversarial and DDIL scenarios (GPS spoofing, comm loss, DoS, low battery, etc.).
  • Demonstrate the complete Zero-Trust mission workflow on the Arculus testbed.
