# Assessment Questions/Answers

## Question 1

**What action initiates the brute force access attempt during mission execution?**

A. Uploading the mission manifest file

B. Clicking Execute Mission

C. Selecting Simulate Brute Force SSH from the simulation controls

D. Navigating to the Mission Planning Dashboard

**Correct Answer**: Selecting Simulate Brute Force SSH from the simulation controls

## Question 2

**During the brute force simulation, which system behavior indicates unauthorized access attempts?**

A. Immediate mission termination

B. Increased drone battery consumption

C. Authentication failure messages in the Activity Log

D. Changes to mission role assignments

**Correct Answer**: Authentication failure messages in the Activity Log

## Question 3

**What does the Simulate Physical Capture option represent during mission execution?**

A. A network latency issue affecting communication

B. A physical compromise of a mission asset

C. A misconfiguration in mission parameters

D. A system software update during runtime

**Correct Answer**: A physical compromise of a mission asset

## Question 4

**When a physical capture event is detected, what system action is observed in the simulation?**

A. Mission execution accelerates to completion

B. Mission roles are reassigned automatically

C. On-board containers are shut down to protect data

D. Network connectivity is fully restored

**Correct Answer**: On-board containers are shut down to protect data

## Question 5

**Why is the mission aborted in safe mode during this simulation?**

A. The mission exceeds its maximum duration

B. System performance improves unexpectedly

C. Mission integrity is compromised by disruption events

D. The operator manually stops the mission without reason

**Correct Answer**: Mission integrity is compromised by disruption events
