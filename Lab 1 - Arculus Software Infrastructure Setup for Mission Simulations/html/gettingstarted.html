Purpose of the Lab

Purpose of this lab is to broaden Infrastructure-as-Code (IaC) and Zero-Trust edge-computing skills by using Terraform to provision and configure resources for the Arculus platform. You will perform hands-on activities on Terraform fundamentals such as providers, variables, resources, security groups, user_data, and outputs, launch Ubuntu EC2 instances with strict SSM-only access, configure network guardrails, and deploy a sample web interface to learn how Terraform automates cloud resource creation. You will also prepare the environment for the Arculus testbed to understand how Zero-Trust, microsegmentation, and controlled service access operate in distributed edge systems.

Goals/Outcomes
  • Get familiar with using Terraform to provision and manage cloud infrastructure on AWS.
  • Go through the fundamentals of Terraform, e.g., providers, variables, resources, security groups, user_data, outputs, and state management.
  • Deploy an example Ubuntu instance and configure strict SSM-only access to understand how secure, reproducible infrastructure can be created without manual setup.
  • Prepare and configure the environment required for the Arculus Zero-Trust platform to demonstrate how Terraform automates network guardrails, microsegmentation, and controlled service access across distributed systems.

Before you begin...Reference Links
  • Terraform

    An Infrastructure-as-Code tool used to provision, configure, and manage cloud resources in a reproducible and automated way.

  • AWS EC2

    A cloud compute service for launching virtual machines where we will deploy Ubuntu instances for the Arculus environment.

  • Arculus Platform

    A Zero-Trust edge-computing framework that enables secure, microsegmented communication between distributed mission, adversary, and research nodes.
