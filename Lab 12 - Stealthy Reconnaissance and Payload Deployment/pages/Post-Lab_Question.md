# Post-Lab Question 1

**1. At what point does the mission behavior diverge between normal and compromised scenarios?**

a. When the surveillance drone is deployed
b. When reconnaissance is completed
c. When RF spectrum surveillance is detected
d. When the payload drone reaches the target

**Correct Answer:**
C


**2. What immediate system response occurs after RF spectrum surveillance is detected?**

a. The mission is automatically aborted
b. The surveillance drone returns to the GCS
c. Communication between the GCS and payload drone is disrupted
d. The payload is immediately deployed

**Correct Answer:**
C


**3. When communication with the GCS is lost, which operational mode does the payload drone enter?**

a. Manual override mode
b. Fail-safe return-to-home mode
c. Autonomous RL-guided mode
d. Standby idle mode

**Correct Answer:**
C

**4. Why is the payload drone able to successfully complete the mission without active GCS communication?**

a. The drone ignores security constraints
b. The mission is paused until communication resumes
c. The drone uses pre-trained policies and mission constraints
d. The surveillance drone assumes control

**Correct Answer:**
C

**What evidence confirms that the mission was completed successfully under compromised conditions?**

a. The payload drone lands near the GCS
b. RF surveillance messages stop appearing
c. A mission completion message and updated mission status are displayed
d. Communication with the GCS is restored

**Correct Answer:**
C
